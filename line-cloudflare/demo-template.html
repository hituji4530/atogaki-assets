Cloudflareだけで動くしくみ

Lステップなどのツールは、LINE公式の Messaging API の上に「友だちのデータベース」と「時間になったら送る仕組み」を載せたものです。その2つを Cloudflare の無料枠で用意すると、同じことが自前でできます。

LINE公式アカウント友だち追加・メッセージ・ボタンのタップが届くMessaging API
WorkersWebhookを受けてタグ付け・自動返信。管理画面もここから配信POST /webhook
D1（SQLite）友だち・タグ・シナリオ・送信履歴を保存friends / tags / …
Cron Triggers毎分起動して、時間が来たステップをプッシュ* * * * *

有料ツールとの違い

月額
Cloudflare は無料枠で始められる。LINE側の通数料金はどちらでも同じようにかかる
データの持ち主
タグや履歴は自分の D1 にあるので、SQLで書き出せる。ツールの乗り換えでタグを失う問題がない
自分で用意するもの
フォーム・予約・決済連携・リッチメニュー切り替え・権限管理・障害対応などは自作か、既存のOSSを使う
このデモの範囲
友だち管理、タグ、条件分岐つきステップ配信、キーワード応答、ボタン（postback）でのタグ付け、セグメント配信
